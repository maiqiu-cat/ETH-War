# 战场音频（背景音乐 + 战斗音效）

> 2026-10-01 第二版：用户认为第一版（纯程序合成）「太闷、太单调」，枪炮声「太单一、听不出来」。在试听页选定：**平静用 M2，激战用 M1，胜利用 M3**；音效和实战混音比例按试听版接入。试听材料在本机 `audio-demos/2026-10-01/`（不入库）。

## 组成

| 部分 | 来源 | 文件 |
| --- | --- | --- |
| 配乐 | `tools/audio/compose.py` 编曲，用 MuseScore_General 音色库（MIT）渲染 | `src/audio/assets/music-*.m4a`（共 2.66 MB） |
| 音效 | `tools/audio/sfx.py` 多层合成；号角和号曲用音色库里的真实铜管渲染 | `src/audio/assets/sfx-*.m4a`（33 个，约 1.1 MB） |
| 清单 | `tools/audio/build_assets.py` 生成 | `src/audio/assets/manifest.json`（循环点、时长、峰值、响度） |
| 引擎 | `src/audio/engine.ts` | 加载、配乐切换、播放、避让、空间化、开关、离线预览 |
| 纯逻辑 | `src/audio/mix.ts` | 空间化、限流、变体、强度、切换滞后、爆炸分级、呼啸对齐、避让参数（有单测） |

Vite 会把所有 `.m4a` 打成带哈希的 `assets/*.m4a`，线上按一年不可变缓存。打包后的 JS 只多了一份很小的清单。

## 配乐逻辑

| 状态 | 曲目 | 说明 |
| --- | --- | --- |
| 平静 `calm` | M2 暗涌（C 小调 120 BPM） | 整曲 64 秒无缝循环 |
| 激战 `battle` | M1 铁血进行曲（D 小调 100 BPM） | 每次进入都从前奏开始：军鼓滚奏加镲片自然引入，之后在第 4–32 小节（67.2 秒）之间循环 |
| 胜利 `victory` | M3 破晓冲锋（D 大调 132 BPM）第 12–20 小节 | 号曲响起后约 2.6 秒进入，约 17 秒，结束前 1.5 秒交还给当前强度对应的曲目 |

- **强度**：`musicIntensity()` 由最近 5 秒的主动成交流量、战线偏离中心的程度、近 1 分钟的大单和爆仓数量合成；任意一方猛攻基地时至少为 0.85。用 `smoothIntensity` 平滑：上升约 3 秒跟上，回落约 9 秒。
- **切换滞后**（`MusicModeSwitch`）：强度 ≥ 0.6 并持续 2 秒，切到激战；≤ 0.4 并持续 12 秒，才回到平静。中间值会把计时清零。切换时旧曲 3 秒淡出，新曲 2.5 秒淡入。
- **避让**（`duckMusic`）：大爆炸时音乐压到 55%；毁灭级爆炸和爆仓压到 35%，0.4 秒后用 1.8 秒恢复；胜利号曲时压到 15%，持续约 2.4 秒。

## 音效映射

| 战场事件（`world.ts`） | 资源 | 说明 |
| --- | --- | --- |
| 前线对射 | `rifle_bull`（6 个变体）/ `rifle_bear`（6 个） | 牛方明亮，熊方厚重。激烈时有 8% 的概率换成机枪连发 `mg_*`，最多每 1.5 秒一次 |
| 大单开炮 | `cannon`（3 个） | 音量随规模在 0.75–1 之间变化 |
| 着弹爆炸 | `expl_s/m/l/xl`（各 2 个） | `explosionTier(size)` 决定分级；l 和 xl 会触发避让 |
| 爆仓 | `whistle` 后接 `expl_xl` | 呼啸从 `whistleOffset(1.8, 飞行时间)` 处开始播，保证呼啸的结尾正好落在着弹那一刻 |
| 期权大单 | `flare`（2 个） | — |
| 新回合 | `horn` | 圆号、小号、定音鼓、镲 |
| 胜利 | `fanfare_bulls`（大调）/ `fanfare_bears`（小调），之后接 M3 | — |

- **共同处理**：
  - **变体**：用 `VariantPicker` 挑选，同一种声音连续两次不会用同一个变体。
  - **音高**：每次播放速率随机偏移 ±3%，避免听起来像同一个录音反复播放。
  - **限流**：每秒最多步枪 10、机枪 1（每 1.5 秒）、坦克炮 4、爆炸 6、呼啸 3、信号弹 2。
- **空间化**（`spatial`）：
  - 左右声道 = 屏幕位置 x × 0.85。
  - 音量 = `1/(1+距离/160)`，最低 0.12；俯瞰镜头（距离约 150）时约 0.52。
  - 远处加低通滤波，从 16 kHz 逐渐降到 2.2 kHz：越远越闷，听起来有距离感，但不会听不到。

## 混音电平

| 位置 | 设置 |
| --- | --- |
| 配乐总线 | 0.5。曲目母带约 −16 dBFS RMS，所以配乐底层约 −24 dBFS |
| 音效 | 按 `SFX_GAIN` 设置（步枪 0.75 … 爆炸和炮 1） |
| 主输出 | 0.9 → 28 Hz 高通 → 压限器（−10 dB、6:1、2 ms/200 ms） |

验证结果：爆炸比配乐底层高约 16 dB（用户认可的试听版 S6/S7 约 12–13 dB）；峰值 0.83，不爆音。

## 默认开启

1. 页面加载时 `audio.boot()` 会创建音频上下文、**预加载并解码全部 36 个文件**，然后尝试 `resume()`。浏览器允许自动播放时（经常访问的网站、站点设置允许声音，或使用自动播放标志），平静曲会直接开始。
2. 浏览器拦截时，状态是 `locked`，底部显示「点击画面任意位置，开启战场音效」。画面上任何一次点击、按键或触摸都会调用 `unlock()`，立刻出声。资源已经提前加载好，不用等待。
3. 右上角的喇叭按钮或 **M 键**可以关闭声音，选择记在 `localStorage['ew.sound']`。URL 加 `?sound=0` 可临时关闭。
4. 页面隐藏时会暂停（`suspend`），回来后自动恢复。

### 无缝循环怎么检查

把文件解码，取 `[loopStart, loopStart+loopLength)` 这一段首尾拼接，检查两点：

- **接缝跳变**：接缝处的样本跳变，应该小于全曲相邻样本跳变的 99.9 分位数。
- **首尾对齐**：用互相关比较 `loopEnd` 之后和 `loopStart` 之后的 0.4 秒，最佳偏移应为 0。

2026-10-01 的结果：

| 曲目 | 偏移 | 相关度 | 接缝跳变 | 全曲 p99.9 |
| --- | --- | --- | --- | --- |
| calm | 0 | 0.995 | 0.005 | 0.26 |
| battle | 0 | 0.980 | 0.047 | 0.32 |

## 局限

- 音色来自 GM 规格的免费音色库，弦乐和铜管的质感比不上商业采样库。可以按同样的管线换成更好的音色库，注意许可证。
- 解码后的音频约占 60 MB 内存（48 kHz 浮点），桌面端没问题；移动端如果要优化，可以降采样率或者改用流式加载。
- 自动播放是否被允许由浏览器决定，网页无法绕过。
