# 0006：逻辑层只产出 i18n 键

- 状态：采用

## 背景

用户要求界面支持中英文切换。战况播报和流水标签原本是逻辑层直接生成的英文句子。

## 决定

- `narrate()` 返回 `StatusKey`，`FeedItem` 增加 `type: FeedType`。界面层用 `t('status.<key>')`、`t('feed.<type>')` 取文案。
- 字典放在 `src/ui/i18n.ts`。`tests/i18n.test.ts` 检查两份字典的键集合一致、占位符一致，并覆盖所有状态键和事件类型。
- 语言优先级：URL → localStorage → 浏览器语言。切换时广播，HUD 重新渲染静态和动态文案。

## 后果

- 加语言或改文案时不用碰逻辑层，测试能拦住漏翻译。
- 动态内容要记得在 `applyLang()` 里重新渲染，这一步需要人工保证。

## 何时重新评估

文案多到需要翻译平台或复数规则时，换成 i18next 一类的库。
