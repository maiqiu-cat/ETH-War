# 0007：HDR 后期，发光靠提高颜色亮度

- 状态：采用

## 背景

用户要求「动画效果更精美」。原版有发光的战线和有电影感的镜头。

## 决定

- 管线：RenderPass（HalfFloat、4×MSAA）→ UnrealBloom → Finish（移轴、饱和度、色温、暗角）→ OutputPass（ACES 色调映射）。
- 要发光的东西（战线、火焰、曳光弹、炮弹、冲击环、胜利线）都给 HDR 颜色或强度，**不要靠降低 Bloom 阈值**。
- 每套光照预设有自己的 Bloom 强度和阈值、色温、暗角。夜晚的战线发光要单独压低。
- `?post=0` 或 `?q=low` 可以关闭后期。

## 后果

- 发光可控，白天的白墙不会泛光；三套光照都调过。
- 关掉后期时，自定义 ShaderMaterial 的颜色会显得偏暗（色彩空间处理不同），这是已知的不一致。
- 移轴只作用于画布，HUD 和 CSS2D 标签不受影响。

## 何时重新评估

- 移动端性能不够时，在低配档关掉 MSAA 和 Bloom，或者降低渲染分辨率。
- 需要选择性 Bloom（只让特定物体发光）时，改用分层渲染或 selective bloom。
