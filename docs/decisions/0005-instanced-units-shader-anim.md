# 0005：单位用 InstancedMesh，肢体动画放在着色器里

- 状态：采用

## 背景

实盘行情下场上同时有 2,000 多名士兵和近百辆坦克。要有行军、开火、受击、倒地这些动作，同时保持 60 FPS。

## 决定

- 士兵和坦克各用一个 `InstancedMesh`，容量分别是 5000 和 220；空闲槽位用缩放为 0 的矩阵隐藏。
- 几何体按部件打上 `aPart` 标记，实例属性 `aAnim = (phase, moving, fire, flash)`。摆腿和后坐在顶点着色器里做，阴影用 `customDepthMaterial` 做同样的变形。
- 整体的位移、朝向、倾倒、缩放仍然由 CPU 每帧写矩阵。

## 后果

- 两个 draw call 画全部单位，CPU 每帧只写矩阵和 4 个浮点数。
- 动作种类受「刚体部件 + 着色器公式」限制，做不了真正的骨骼动画。
- 加部件时要同时改着色器分支和文档里的表，容易漏。

## 何时重新评估

- 换成美术提供的 glTF 骨骼模型时，可以考虑顶点动画贴图（VAT）或 `InstancedSkinnedMesh` 方案。
- 单位数再上一个量级时，加 LOD（远处改用 billboard 或点精灵）。
